# 💰 Expense Tracker (Python)

## 📌 Description
The Expense Tracker is a simple Python-based mini project that helps users manage daily expenses. Users can add expenses by category, view all expenses, and calculate total spending using a menu-driven system.

---

## 🚀 Features
- Add expenses by category (Food, Travel, etc.)
- Automatically updates category-wise spending
- View all recorded expenses
- Calculate total expense
- Menu-driven interactive system

---

```bash
python expense_tracker.py
